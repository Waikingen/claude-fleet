# Claude Fleet — Styleguide

Design tokens for the ClaudeFleet macOS app (SwiftUI). Source of truth for UI work in this repo.

## Design Tokens
- Background: `#070c1a` (midnight navy)
- Accent: `#00d4ff` (cyan)
- Risk: `#ff6040` (red-orange)
- Active: `#34d399` (green)
- Glass cards: `rgba(255,255,255,0.035)` bg, `rgba(255,255,255,0.07)` border
